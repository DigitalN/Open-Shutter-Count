# Matt Pocock's skills

The skill folders here are copied from [mattpocock/skills](https://github.com/mattpocock/skills)
at commit `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d` (plugin v1.3.2), MIT licensed (see `LICENSE-mattpocock-skills`).

They live in the repo, not as a plugin, so they also load in Claude Code cloud sessions,
which don't install plugins from `.claude/settings.json`.

First run `/setup-matt-pocock-skills` once to configure the issue tracker, triage labels and docs location.

To update, copy the latest folders listed in that repo's `.claude-plugin/plugin.json` over these.
Don't also install the `mattpocock-skills` plugin locally, or every skill shows up twice.
